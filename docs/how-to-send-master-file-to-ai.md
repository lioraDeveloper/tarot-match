# איך לשלוח ל־AI את קובץ המאסטר

הקובץ המלא: `docs/ai-master-tarot-file.md`  
(אפשר להעתיק גם ל־Google Docs / Notion)

---

## אפשרות 1 — הכי פשוטה (ChatGPT / Claude וכו׳)

1. פותחים שיחה חדשה  
2. מדביקים בהתחלה את הסעיפים **א + ב + ד** מהקובץ  
   (הוראה קבועה + איך קוראים + סגנון)  
3. מדביקים את **הקלפים הרלוונטיים** לפריסה (מהסעיף ה)  
4. מדביקים את **תבנית הפריסה** (סעיף ו) וממלאים  
5. שולחים

אם השיחה ארוכה מדי — פותחים שיחה חדשה ושוב מדביקים את הכללים + הקלפים.

---

## אפשרות 2 — Custom GPT / Project (אם יש)

1. יוצרים Project / Custom GPT  
2. מעלים את כל קובץ המאסטר כקובץ קבוע  
3. בהוראות הבוט כותבים:  
   «תעבוד רק לפי קובץ המאסטר. אל תנחש.»  
4. בכל פריסה שולחים רק: שאלה + 3 קלפים + חומר חסר אם יש

---

## אפשרות 3 — Google Doc חי

1. מעתיקים את הקובץ ל־Google Doc בשם:  
   `מאסטר קלפים — לא לנחש`
2. אחרי כל קלף חדש — מעדכנים שם  
3. לפני פריסה:  
   מעתיקים ל־AI את החלק הרלוונטי  
   או מורידים PDF/Doc ושולחים כקובץ

---

## משפט קסם לכל שיחה

```text
הנה קובץ המאסטר / החוקים שלי.
תעבוד רק לפיו + לפי החומר שאני שולחת עכשיו.
אם חסר מידע — תגיד שחסר, אל תנחש.
כתוב בעברית פשוטה כמו מדריך.
```
