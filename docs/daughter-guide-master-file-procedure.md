# מדריך לבת — איך עוזרים לאמא לעבוד עם AI וקובץ המאסטר

**למי זה:** לבת שמסבירה לאמא  
**המטרה:** שאמא תוכל לשמור סיכומי קלפים ולעשות פריסות בלי שהידע ייעלם  
**כלים:** טלפון + מחשב + Google Docs + ChatGPT (או Claude)

---

## מה חשוב שתביני לפני שמתחילים

ה־AI **לא זוכר באמת** את כל הקלפים בין שיחות.  
לכן אמא חייבת קובץ שמירה משלה:

**שם הקובץ:** מאסטר קלפים  
**איפה:** Google Docs  

הכלל:
1. AI מסכם קלף  
2. אמא מעתיקה לקובץ המאסטר  
3. רק אז עוברים הלאה  

בלי העתקה לקובץ — החומר נעלם.

---

## חלק א׳ — הכנה חד־פעמית (עדיף במחשב)

### 1) פותחים Google Doc
1. נכנסים ל־`docs.google.com`
2. מתחברים עם ג׳ימייל של אמא
3. לוחצים על **מסמך ריק**
4. משנים את השם ל: **מאסטר קלפים**

### 2) שמים תבנית בפנים
1. מעתיקים לקובץ את התבנית מהקובץ:
   `docs/ai-master-tarot-file.md`
2. או מדביקים תבנית פשוטה כזו לכל קלף:

```text
### שם הקלף:
מסר קצר להעברה:
מה להבין:
תומך:
חוסם:
כשזה צד ב׳:
הצעד עכשיו:
הערות:
```

### 3) פותחים ChatGPT בטלפון ובמחשב
- בטלפון: אפליקציית ChatGPT  
- במחשב: `chatgpt.com`  
(אפשר גם Claude)

### 4) מדביקים ל־AI הודעת פתיחה קבועה
```text
אתה מורה מקצועי לטארוט.
תעבוד רק לפי החומר שאני שולחת.
אל תנחש ואל תמציא.
לכל קלף תן סיכום מוכן להעתקה בפורמט:
שם הקלף / מסר קצר להעברה / מה להבין / תומך / חוסם / צד ב׳ / הצעד עכשיו.
בסוף כל קלף כתוב: "העתיקי את זה עכשיו לקובץ המאסטר".
```

## חלק ב׳ — איך ממלאים קלף (פרוצדורה יומית)

### אפשרות מומלצת: טלפון + מחשב

**בטלפון (אמא):**
1. מצלמת/שולחת ל־AI את המלל או תמונת העמוד של הקלף
2. מבקשת: «תסכם לפי הפורמט הקבוע»
3. בודקת שהסיכום ברור ופשוט

**במחשב (אמא או את):**
1. מעתיקים את הסיכום מה־AI
2. נכנסים ל־Google Doc **מאסטר קלפים**
3. מוצאים את שם הקלף
4. מדביקים במקום הנכון
5. מוודאים שנשמר (Google Docs שומר לבד)

### אם עובדים רק מהטלפון
1. אפליקציית ChatGPT → מקבלים סיכום  
2. לחיצה ארוכה על הטקסט → **העתק**  
3. אפליקציית Google Docs → קובץ **מאסטר קלפים**  
4. לחיצה ארוכה → **הדבק** במקום הקלף  

---

## חלק ג׳ — איך עושים פריסה ללקוח

דוגמה לשאלה:
«האם העסק הזה נכון עבורי?»

### שלבים
1. אמא שולפת 3 קלפים פיזיים  
2. פותחת את קובץ **מאסטר קלפים**  
3. מעתיקה ממנו את הסיכומים של 3 הקלפים  
4. מדביקה ל־AI עם הטקסט הזה:

```text
השאלה: האם העסק הזה נכון עבורי?
הקלפים:
- צד א׳: ...
- מרכז: ...
- צד ב׳: ...

הנה הסיכומים מהמאסטר:
[מדביקים]

תעבוד רק לפי החומר הזה.
אל תנחש.
מרכז = כיוון.
צדדים = מחזק/חוסם.
תן:
1) כיוון
2) מחזק/חוסם
3) מסר אחד ברור
4) הצעד עכשיו
```

5. אמא מעבירה ללקוח את התשובה (וואטסאפ / מכתב)

---

## חלק ד׳ — חוקים שאת חייבת להזכיר לאמא

1. AI לא שומר לבד לתמיד  
2. כל קלף חייב להיכנס לקובץ המאסטר  
3. בפריסה מדביקים מהמאסטר — לא מהזיכרון של השיחה  
4. אם קלף חסר במאסטר — לא נותנים לו לנחש  
5. עברית פשוטה תמיד  

---

## חלק ה׳ — תסריט קצר איך את מסבירה לאמא

«אמא, ה־AI זה כמו עוזר חכם, אבל הוא שוכח.  
לכן יש לנו מחברת דיגיטלית בשם מאסטר קלפים.  
הוא כותב סיכום — אנחנו מעתיקות למחברת.  
כשיש לקוח, אנחנו לוקחות מהמחברת את 3 הקלפים והוא מחבר תשובה.»

## חלק ו׳ — תרגול ראשון ביחד (15 דקות)

1. פותחות יחד את Google Doc **מאסטר קלפים**  
2. שולחות ל־AI קלף אחד (למשל השוטה)  
3. מעתיקות את הסיכום לקובץ  
4. עושות פריסת דמה של 3 קלפים  
5. מדביקות ל־AI ומבקשות מסר אחד  

אם זה עבד פעם אחת — אמא כבר מבינה את השיטה.
