מדריך לבת — איך עוזרים לאמא עם AI וקובץ המאסטר
(אפשר להעתיק את כל ההודעה הזו לוואטסאפ)

היי, צריך ממך עזרה פשוטה בלי להיות מתכנתת.

הבעיה:
כשאני מלמדת AI קלפים הוא שוכח בין שיחות.
אז אנחנו חייבים קובץ שמירה קבוע.

הפתרון:
יש קובץ בגוגל דוקס בשם: מאסטר קלפים
AI מסכם → אני מעתיקה לקובץ → ככה זה לא נעלם.

————————
מה תפקידך
1. לעזור לי להקים את הקובץ פעם אחת
2. להראות לי איך מעתיקים ומדביקים
3. לעשות איתי תרגול קצר על קלף אחד
4. לוודא שכל קלף שסיכמנו נשמר ישר במאסטר

————————
חלק 1 — פעם אחת במחשב
1. נכנסים ל docs.google.com
2. מתחברים לג׳ימייל שלי
3. פותחים מסמך ריק
4. קוראים לו: מאסטר קלפים
5. מדביקים לתוכו תבנית לכל קלף:

שם הקלף:
מסר קצר להעברה:
מה להבין:
תומך:
חוסם:
כשזה צד ב׳:
הצעד עכשיו:
הערות:

————————
חלק 2 — איך לומדים קלף
1. אני שולחת לAI את החומר של הקלף
2. אנחנו לומדות יחד עם הסברים שאלות ותרגילים
3. רק כשאני אומרת "הבנתי — סכם לקובץ"
4. הוא נותן סיכום סופי
5. ישר מעתיקים את הסיכום לקובץ מאסטר קלפים
6. רק אז עוברים לקלף הבא

חשוב:
לא לחכות לסוף כל הקלפים.
כל קלף נשמר מיד.

————————
חלק 3 — מקשים במחשב
העתק: Ctrl + C
הדבק: Ctrl + V

במק:
העתק: Cmd + C
הדבק: Cmd + V

בנייד:
לחיצה ארוכה על הטקסט → העתק
לחיצה ארוכה בקובץ → הדבק

————————
חלק 4 — כשיש לקוח ופריסה
1. שולפים 3 קלפים
2. פותחים את מאסטר קלפים
3. מעתיקים משם את הסיכומים של 3 הקלפים
4. מדביקים לAI עם השאלה
5. כותבים לו:

השאלה: ___
הקלפים:
צד א: ___
מרכז: ___
צד ב: ___
הנה הסיכומים מהמאסטר:
[מדביקים]

תעבוד רק לפי החומר.
אל תנחש.
מרכז = כיוון
צדדים = מחזק/חוסם
תן מסר אחד ברור + הצעד עכשיו
