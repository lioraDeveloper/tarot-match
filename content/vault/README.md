# כספת תוכן — 3 שכבות

הפרדה ברורה בין **ידע**, **ניסויים**, ו**מה שנכנס לקליק**.

```
content/vault/
  source/      ← חומר ספר / לימוד (הסוכן לומד מכאן)
  drafts/      ← אופציות וניסויים (עדיין לא המוצר)
  published/   ← מסר אחד + מסלול ירוק שנעולו למוצר (האפליקציה טוענת רק מכאן)
```

| שכבה | מי קורא | נכנס לאפליקציה? | מטרה |
|------|---------|------------------|------|
| **source** | את + הסוכן | לא | להבין את הקלף לפי הספר |
| **drafts** | את + הסוכן | לא | לשמור הרבה אופציות עד שמחליטים |
| **published** | האפליקציה | כן | מסר קצר אחד ברור + מסלול ירוק סופי |

## זרימת עבודה (חובה)

1. לומדים מ־`source/` (מדויק לפי הספר).
2. כותבים / משווים אופציות ב־`drafts/<card>/`.
3. רק כשאת אומרת במפורש **«נעול»** או **«שמור למוצר»** — מעבירים גרסה אחת ל־`published/`.
4. בקליק למשתמש יוצא **רק** מה ש־published.

## כלל לסוכן
- מידע להבנה → `source/`
- הצעות וגרסאות → `drafts/`
- שינוי מוצר חי → רק אחרי אישור נעילה ל־`published/`
