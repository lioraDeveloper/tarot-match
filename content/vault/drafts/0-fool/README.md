- `source/` = חומר ספר ללמידה (מקור ידע לסוכן)
- `drafts/0-fool/` = ניסויים / כמה גרסאות
- `published/` = מה שנכנס לקליק במוצר (מסר אחד ברור)

A. חיבור פתוח ומרגש. השיעור: לא לברוח כשצריך לבחור. אם תישארו — יש לאן ללכת.  
B. (ריק — להוסיף כאן גרסאות נוספות בלי לגעת ב־published)

## מסלול ירוק
עדיין **לא נעול**.  
הגרסה שרצה עכשיו במוצר מסומנת `draft-in-use` ב־`published/cards.he.json`.  
כשתאשרי קונספט — מעתיקים לכאן את הגרסאות, ואז מעבירים אחת ל־published ומסמנים `published`.

## מה הסוכן מותר לעשות כאן

- להציע טיוטות **לכאן**
